If you want to use your local environment instead of the Azure Cloud
Shell you will need to fulfil the following requirements:

- Linux shell or Azure Cloud Shell
- Azure CLI -
  download [here](https://docs.microsoft.com/en-us/cli/azure/install-azure-cli?view=azure-cli-latest)
- Terraform CLI -
  download [here](https://www.terraform.io/downloads.html)

We tested the deployment with following version:

- Azure CLI 2.0.66 and above
- Terraform v0.12 and above
