1.  Export your tenant id by
    executing `export tenantId="xxxxxxxx-xxxx-xxxx-xxx-xxxxxxxxxxxx"`
2.  Export your subscriptions id by
    executing `export subscriptionId="xxxxxxxx-xxxx-xxxx-xxx-xxxxxxxxxxxx"`
3.  Run `destroy.sh` to destroy your deployment. This will destroy all
    created resources!
