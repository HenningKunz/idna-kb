The panagenda iDNA Applications web interface is compatible with many
HTML5 capable devices and browsers. Recommended browsers are Chrome (64
bit) and Firefox (64 bit).

  

# Browser security and Network Access:

No special web browser security settings are required to runt he
panagenda iDNA Applications web interface.

To access the panagenda iDNA Applications web interface, you need to
have access to the panagenda iDNA Applications appliance via TCP/IP,
port 80 (HTTP) and port 443 (HTTPS).
