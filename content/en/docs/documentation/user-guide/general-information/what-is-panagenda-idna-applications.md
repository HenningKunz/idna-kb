panagenda iDNA Applications is delivered as a virtual appliance that
provides next generation data analytics for your HCL Notes / Domino
applications. This helps you reduce your cost of ownership, plan your
migration, and whatever else your next steps may be. It offers reports
on design complexity of applications and gives insights into the
application landscape for migration, modernization, transformation and
optimization purposes. panagenda iDNA Applications offers
administrators, developers and management the means to plan, manage
execute and monitor a future-proof  application strategy.

In order to do so, iDNA Applications provides:

- Environment and inventory overviews
- Insights into usage from HCL Notes Rich clients and browsers
- Usage information per hierarchical department and user for analyzed
  databases
- Analytics on design and source code complexity
- Detailed „Design Insights" based on source code search patterns
- Design similarity and identification of „Template Candidates"
- Continuous collection of data (overview, usage and design changes)
- Platform wide code searches
- The option to **define your own custom insights, charts and
  dashboards **
