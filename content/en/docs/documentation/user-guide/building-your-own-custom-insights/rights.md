Administrators are only allowed to edit the rulesets, insights and
patterns created directly on the iDNA Applications appliance itself.
Elements and rulesets imported from other systems can be cloned and or
removed but the individual elements of these imported rulesets cannot be
changed.

Elements created by panagenda cannot be changed or removed. They can be
disabled (rulesets) and or cloned if necessary.
