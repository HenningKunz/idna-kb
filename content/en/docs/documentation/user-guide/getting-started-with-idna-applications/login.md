Access to panagenda iDNA Applications is on a per user basis. It
requires a username and password to login.

{{% callout type="info" %}}

Keep in mind that both username and password are case sensitive! 

{{% /callout %}}

User accounts can be created by the administrator. Please refer to the
[kbase topics about user management](/kb/user-management/) for
information on how to reset passwords and create user accounts.
