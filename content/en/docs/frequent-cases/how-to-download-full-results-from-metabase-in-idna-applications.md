In iDNA Applications, the export of Metabase data only works properly if
the correct appliance URL is set in its configuration.

![](/images/kb/28574571/28574574.png)

![](/images/kb/28574571/28574573.png)

  

If you have problems with exporting, please try the following steps:

1.  Go to this URL on your appliance (**https://*\<iDNA Applications
    FQDN or IP\>*/metabase/**)** **and log in with
    **admin@metabase.local   
      
    **
2.  Click on the **cogwheel icon** in the upper right corner in the
    Metabase user interface and select **Admin**:  
    ![](/images/kb/28574571/28574572.png)  
      
3.  Navigate to the **General** section and enter the correct **Site
    URL:**  
    ![](/images/kb/28574571/28574575.png)  
      
4.  Please reload the iDNA Applications page in your browser.
