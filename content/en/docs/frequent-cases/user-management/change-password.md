To change the password of the user logged in, follow these steps:

1.  Go to this URL of your appliance **https://*\<FQDN or
    IP\>*/idna/sys/accounts**
2.  Log in with an **Administrator **user (default user: *config*;
    PW: *config*)
3.  Change the password in the **Change Password **section:  
    ![](/images/kb/28574371/28574372.png)
4.  Click **update** 
5.  Log out by clicking the username in the upper right corner
6.  Try logging back in with the new credentials
