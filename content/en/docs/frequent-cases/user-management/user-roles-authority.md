There are three types of users:

- **Viewer**: Can access all analysis and metrics data and interact with
  the visualizations but is restricted from changing system settings.
- **Administrator**: Can access all analysis and metrics data and
  interact with the visualizations and is allowed to manage system
  settings. Including creating accounts and resetting user passwords.
- **API - Metadata:** Can access the appliance via
  the [API](/kb/api-documentation---catalog-custom-properties/)
